# Project working preferences

- To save tokens, do not launch the app UI, start a web server, or perform visual testing unless the user explicitly requests it.
- The user will run the web server and test UI changes.
- Run only targeted unit tests, type checks, or build checks relevant to the changes. Avoid broad or unrelated validation.
- Unless specified otherwise, apply all changes to both the web and mobile versions of this app.
- Apply these preferences throughout this project, including in new chats.
