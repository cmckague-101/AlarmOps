# Contributing to FireOps

1. Create a branch from `main`.
2. Make one focused change.
3. Run `npm install`, `npx tsc --noEmit`, and `npx expo config --type public`.
4. Commit with a clear message.
5. Open a pull request before merging to `main`.

Do not commit credentials, employee private information, medical records, government IDs, production databases, or signing certificates.
