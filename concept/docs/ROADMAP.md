# FireOps Roadmap

- Contractor and employee experiences
- Dashboard, maps, fleet, communications and movable More screen

- Multi-tenant backend and authentication
- Company and role-based permissions
- Secure document and image storage
- Offline synchronization and audit logs
- Push notifications
- Automated tests and continuous integration

## Commercial integrations
- QuickBooks Online
- Motive fleet data
