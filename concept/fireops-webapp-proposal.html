Current repository provides broad UI foundation and useful workflow prototypes. Production launch requires real authentication, shared data, storage, security policies, web compatibility, and operational testing.

Verdict: Vercel and Supabase fit initial launch.

02 · Launch Scope

Focused internal operations platform

First release should solve company operations, records, fleet readiness, personnel coordination, and manual finance workflows. External ecosystems and speculative features should remain deferred.

Included in initial application

  • Email login and company-only invitations
  • Admin, Office, Crew Lead, and Employee roles
  • Dashboard backed by shared operational data
  • Company roster and availability
  • Incident map, details, resources, and crew assignments
  • Fleet assets, inspections, issues, and equipment binders
  • Internal company messaging
  • Qualifications and credential documents
  • Inventory checkout and return
  • Company documents, training, and evaluations
  • Manual payroll, receipts, invoices, and PDF downloads
  • Company settings and branding

Excluded or deferred

  • FireOps AI assistant
  • Invoice OCR and AI import
  • Payroll AI hour detection
  • FireOps Intelligence
  • Marketplace and seller messaging
  • Workforce discovery and job board
  • Customer or external company portals
  • Cross-company profiles, messaging, and data sharing
  • Multi-company administration
  • QuickBooks and Motive integrations for initial release
  • Push notifications until core web workflows stabilize
03 · Architecture

Vercel frontend. Supabase backend.

Expo React Native Web can remain frontend foundation. Supabase supplies identity, relational data, files, realtime updates, and protected server functions.

FRONTEND

Expo Web

Responsive browser UI, role-aware navigation, forms, dashboards, and maps.

→
HOSTING

Vercel

Static web deployment, custom domain, environment configuration, preview deployments.

→
BACKEND

Supabase

Auth, Postgres, Storage, Realtime, Row Level Security, and Edge Functions.

Vercel responsibilities

  • Production Expo web build and deployment
  • Custom domain and HTTPS
  • Environment variables
  • Preview environments and release checks
  • Browser routes and deep links

Supabase responsibilities

  • Email/password or magic-link authentication
  • Company and operational records
  • Private photos, credentials, receipts, and PDFs
  • Realtime chat and availability updates
  • Invitations and protected server operations
  • Database-enforced access policies
Single-company design: Every business record should still contain company_id. Seed one company and prevent users from creating others. This preserves data isolation and avoids future schema reconstruction.
04 · Production Requirements

Work remaining

UI coverage is broad. Main effort now shifts toward backend engineering, browser adaptation, security, workflow completion, and quality assurance.

01

Authentication and invitations

Implement Supabase Auth, admin-only invitations, invite acceptance, password reset, session handling, account suspension, and real current-user profiles.

02

Shared data migration

Replace AsyncStorage and seed records with Supabase repositories, database queries, mutations, and realtime subscriptions.

03

Web map implementation

Keep native map for mobile and add MapLibre or Mapbox implementation for web. Cache public incident feeds through server functions.

04

Operational workflows

Add incident CRUD, assignments, resource readiness, fleet CRUD, issue ownership, status transitions, service history, and audit timestamps.

05

Internal messaging

Create authorized channels, realtime messages, unread state, urgent acknowledgement, channel membership, and retention controls.

06

Documents and qualifications

Tie records to real users, use private storage, add admin review, expiration alerts, browser PDF export, and verification history.

07

Manual finance workflows

Replace AI flows with entered hours, pay periods, receipt details, invoice line items, approval statuses, and secure files.

08

Production hardening

Add automated tests, CI, validation, monitoring, migrations, backups, audit logs, accessibility, file limits, and policy documents.

05 · Delivery Plan

Four implementation phases

Sequence reduces risk by establishing identity, security, and shared data before expanding operational and financial workflows.

Foundation

Fix web build and map, create Supabase project and migrations, implement authentication, invitations, company membership, RLS, file storage, and Vercel deployment.

Core operations

Deliver roster, availability, incidents, assignments, fleet CRUD, inspections, issues, and data-backed dashboard.

Internal workflows

Deliver company chat, qualifications, documents, inventory, training, and evaluations.

Finance and hardening

Deliver manual payroll, receipts, invoices, PDFs, audit history, tests, monitoring, security review, and launch QA.
